AD Six-Gene Cognitive Decline Predictor

Research prototype  |  King Abdulaziz University, Department of Computer Science

Clinical input protocol: Enter log2 RMA-normalised expression values from Affymetrix HG-U219 array. Values outside the displayed typical ranges will trigger a calibration warning. All values are in log2 arbitrary units. Adjust each slider to match the patient's array expression value for that probe, then click Predict cognitive trajectory. The form submits data as JSON to the prediction API and displays the structured response.
